# 智能饮食助手

[English](README.md) · 简体中文

一个基于 Qt 的桌面应用，支持拍照识别菜品、记录饮食和营养问答，后端使用 FastAPI 和 MySQL。

## 项目功能

- **拍照识别菜品** — 从食物照片识别菜名，支持用户确认和纠正。
- **饮食和健康记录** — 登记食物份量，查看每日及每周营养汇总，跟踪体重。
- **多轮饮食问答** — 查询历史摄入，计算指定份量的营养，或者询问菜品做法。
- **运动计划与打卡** — 生成每日运动计划，并记录任务完成情况。

## 技术实现

- **视觉微调** — 使用从 ChineseFoodNet 整理的菜品图片对 MiniCPM-V 进行 LoRA 微调。推理时，微调模型先提出菜名，基座模型核验预测。核验未通过时由基座模型重新识别，并补充食材描述。
- **菜谱 RAG 与数据库查询** — 大模型结合对话历史消解指代，生成结构化查询计划。Python 校验计划，用参数化 SQL 查询 MySQL，并按克重计算营养。菜谱问答通过 BGE-M3 和 Chroma 检索 300 篇菜谱，支持可选的 BM25 混合检索。最后由大模型根据数据库结果和菜谱片段回答。

## 项目结构

```text
smart-diet-assistant/
├── src/                    # Qt/C++ 桌面客户端
├── backend/
│   ├── main.py              # FastAPI 接口入口
│   ├── ai/                  # 视觉识别服务与模型客户端
│   ├── rag/                 # 查询规划、检索与回答生成
│   ├── services/            # 饮食、营养与识别业务逻辑
│   ├── dao/                 # 数据库查询
│   ├── database/            # MySQL 建表和初始数据
│   ├── data/                # 菜谱和营养参考数据
│   ├── scripts/             # 建库与辅助脚本
│   └── evals/               # 检索评测
├── dataset/                # 视觉微调数据清单
├── build_dataset.py        # 视觉数据集构建脚本
└── tests/                  # 自动化测试
```
